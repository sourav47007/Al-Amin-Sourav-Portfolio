# Portfolio

A personal site with four working finance tools. Plain HTML, CSS and JavaScript
(ES modules), one Vercel serverless function, no framework and no build step.

| Page | What it is |
|---|---|
| `/` | Home: name, intro, four project tiles, "Now" line |
| `/valuation` | **What's Priced In?** Reverse DCF on SEC EDGAR data |
| `/market` | **Make Me a Market.** Pixel-art market-making game (`/market/bots` explains the bots) |
| `/recon` | **Recon.** In-browser reconciliation engine (Web Worker, nothing uploaded) |
| `/truecost` | **True Cost.** Credit offer decoder (APR via IRR) |
| `/about`, `/notes`, `404` | About, notes, not-found page |

## 1. Deploy (first time, about 10 minutes)

1. Create a **public** GitHub repository and push this folder to it. Public matters: the
   "Source code" links on every project page point there.
2. In [vercel.com](https://vercel.com) choose **Add New → Project**, import the repository,
   leave the framework as **Other** and the build command empty, and deploy. The site
   is static; `api/sec.js` becomes a serverless function automatically.
3. In the Vercel project go to **Settings → Environment Variables** and add
   `SEC_CONTACT_EMAIL` = your email. SEC requires a contact address in the
   User-Agent of every request. Redeploy once after adding it.
4. Open `content/site.js`, set `url` to the address Vercel gave you (or your custom
   domain), run `npm run sync`, commit and push. Every push to `main` deploys.

## 2. Edit your information

Everything personal is in **one file: `content/site.js`**. Name, role, intro, bio,
experience, education, skills, competitions, leadership, links, the "Now" line,
project one-liners, "Why I built it" paragraphs, the case-study text and the
ticker strip. Plain text, no HTML.

After changing the name or URL run `npm run sync` so the `<title>` and social
preview tags in each HTML page are regenerated (they cannot be filled at runtime
because LinkedIn reads them without running JavaScript).

Other things you may want to change:

| What | Where |
|---|---|
| CV | Replace `files/CV_Md_Al-Amin_Rahman_Sourav.pdf` and update `cvFile` in `content/site.js` |
| LafargeHolcim model | Put the spreadsheet at `files/LafargeHolcim_Valuation_Model.xlsx` (the path in `caseStudy.file`) |
| Colours, fonts, spacing | `assets/css/tokens.css` (both themes) |
| Social preview images | `python3 scripts/make-og.py "Your Name" "your-domain.com"` (needs `pip install pillow`) |
| A new note | Add an entry to `notes` in `content/site.js` |
| Add a project tile | Add an entry to `projects` in `content/site.js`, create `newslug/index.html` by copying a project page, and add the tile to `index.html` |

Things that were deliberately left out of the site: phone number, home address, CGPA.
The CV PDF you supplied does contain a phone number and address; replace it with a
web version if you want those off the site too.

## 3. Run locally

```
npm test            # unit tests (Node 20+, no dependencies)
npm run serve       # static preview at http://localhost:8080 (no /api/sec; use presets or manual entry)
npm run dev         # full preview including the SEC function (installs the Vercel CLI on first run)
```

With `npm run serve`, pages must be opened with their file names (`/about.html`,
`/valuation/`). On Vercel, `cleanUrls` gives `/about` and `/valuation`.

## 4. Data

- **SEC EDGAR** (`api/sec.js`): resolves a ticker through `company_tickers.json`,
  fetches `companyfacts`, trims it to five fiscal years of the fields the DCF needs,
  and returns a few KB with `Cache-Control: s-maxage=86400` so Vercel's CDN
  serves repeats for a day. The function identifies itself as
  `Sourav Portfolio <SEC_CONTACT_EMAIL>` and makes at most two SEC requests per
  call, far below SEC's 10 requests/second limit.
- **Offline presets** (`data/presets/`): run `SEC_CONTACT_EMAIL=you@example.com npm run presets`
  on your own computer to snapshot Apple, Microsoft, Nvidia, Coca-Cola, Tesla and
  Walmart (or pass your own list: `npm run presets -- AAPL,MSFT,JNJ`). Until you do,
  the preset menu shows `[DATA NEEDED]` and the tool still works via the live API
  or manual entry.
- **Share prices** are typed by the visitor with an "as of" date. No price feed is used.
- **Recon demo data** (`data/recon-sample/`) is synthetic, generated by
  `assets/js/recon/sample.js` with a fixed seed. `npm run sample` regenerates it.
  No real company's data is used anywhere.

## 5. Tests

`npm test` runs Node's built-in test runner over `tests/`:

- `truecost.test.mjs`: APR/IRR against Regulation Z (12 CFR 1026) Appendix J, Example (i):
  $5,000 advanced, 24 monthly payments of $230, APR 9.69%
  (https://www.consumerfinance.gov/rules-policy/regulations/1026/j/); flat vs reducing
  conversion; BNPL fees and late payments; credit-card payoff.
- `recon.test.mjs`: every expected match in the synthetic sample is found by the
  expected rule; duplicates flagged; 10,000 rows per side in under 5 seconds.
- `valuation.test.mjs`: DCF collapses to NOPAT/WACC at zero growth; reverse DCF
  round trip recovers the input growth; XBRL tag fallbacks and quality notes.
- `market.test.mjs`: distributions, quote validation, settlement P&L and its
  spread/adverse-selection breakdown, position limits, news.

## 6. Structure

```
index.html  about.html  notes.html  404.html
valuation/  market/  recon/  truecost/     one index.html each (market/ also has bots.html)
api/sec.js                                   EDGAR proxy (Vercel function)
content/site.js                              ALL personal content
assets/css/tokens.css, base.css              theme (light + dark), components
assets/fonts/                                Departure Mono, Inter (self-hosted)
assets/icons/                                pixel SVG icons, favicon, touch icon
assets/js/site.js                            header, nav, footer, theme toggle, ticker, content injection
assets/js/shared/                            formatting, URL state, Chart.js theme, lazy KaTeX, icons
assets/js/valuation/                         extract.js, dcf.js, reverse.js, ui.js
assets/js/market/                            engine.js, render.js, ui.js
assets/js/recon/                             parse.js, match.js, match.worker.js, export.js, sample.js, ui.js
assets/js/truecost/                          cashflows.js, irr.js, ui.js
assets/vendor/                               Chart.js, KaTeX, Papa Parse, SheetJS (pinned copies)
data/presets/  data/recon-sample/            EDGAR snapshots (build yourself), synthetic demo
files/                                       CV, model
og/                                          1200×627 social preview images
scripts/                                     sync-meta.mjs, build-presets.mjs, build-recon-sample.mjs, make-og.py
tests/                                       unit tests
vercel.json                                  cleanUrls, caching headers
```

Calculation code is pure (no DOM) and lives apart from the `ui.js` files, so the
tests import it directly.
